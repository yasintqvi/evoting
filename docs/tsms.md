# پیامک ورود با TSMS

درایور پیش‌فرض پیامک `tsms` است. مسیر موجود `/otp/send` برای کاربرانی که نوع احراز هویت آن‌ها SMS است، کد ورود را به شمارهٔ ثبت‌شدهٔ همان کاربر ارسال می‌کند.

تنظیمات محیط:

```dotenv
TSMS_URL=https://www.tsms.ir/url/tsmshttp.php
TSMS_USERNAME=
TSMS_PASSWORD=
TSMS_FROM=
TSMS_OTP_MESSAGE="کد ورود شما: :code"
```

رمز دارای نویسه‌های ویژه را داخل تک‌کوتیشن قرار دهید؛ مقدار خام رمز را وارد کنید، نه نسخهٔ URL-encoded آن. Laravel پارامترهای درخواست را encode می‌کند.

در درخواست آزمایشی واقعی، سرویس HTTP 200 با بدنهٔ `894037823` برگرداند؛ در درخواست بدون اطلاعات اتصال، بدنهٔ `4` بود. بر اساس این مشاهده، درایور عدد مثبت ۹رقمی یا بزرگ‌تر را شناسهٔ پذیرش پیامک در نظر می‌گیرد و پاسخ‌های کوتاه، خالی یا غیرعددی را رد می‌کند. این قاعده بر مبنای مشاهده است، نه قرارداد رسمی دریافت‌شده از سرویس؛ در صورت تغییر قالب پاسخ باید با مستندات TSMS تطبیق داده شود. پذیرش درخواست به معنی تأیید تحویل به گوشی نیست.

پس از تغییر تنظیمات:

```sh
php artisan config:clear
```

درخواست‌ها مهلت ۱۵ ثانیه دارند و خودکار تکرار نمی‌شوند. فقط پس از پاسخ موفق، خود کد برای بررسی OTP ذخیره می‌شود. خطای شبکه یا پاسخ نامعتبر باعث خطای ارسال می‌شود و کد ذخیره نمی‌شود.

تست بدون ارسال پیامک واقعی:

```sh
php artisan test --filter=TsmsDriverTest
```
